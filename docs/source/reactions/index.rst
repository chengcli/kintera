Reaction data and isolated tests
================================

Each page records the pressure quotient, coefficients, source status, numerical
tables and isolated TP/UV validation for one reaction family. Alternative
formulas and phase branches are grouped together. Comparison-only PR fits are
not in the production function registry; legacy public fits with unresolved
provenance remain explicitly labeled. Numerical convergence does not establish
physical validity. See :doc:`../equilibrium_algorithms` for gas products,
constraints, energy coupling and reproduction instructions.
